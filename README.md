# Jessica’s Closet — versão brasileira

Jogo de moda em português brasileiro, pensado para abrir no Safari do iPhone.

## Como testar no iPhone
1. Extraia o ZIP em um serviço de arquivos ou computador.
2. Abra `index.html` em um navegador para testar. Para abrir por um link no iPhone, publique a pasta em um serviço de hospedagem estática (por exemplo, GitHub Pages ou Netlify).
3. No Safari, abra o link e use **Compartilhar → Adicionar à Tela de Início**.

## O que tem nesta versão
- Interface adaptável para celular.
- Categorias de blusas, partes de baixo, vestidos, sapatos, bolsas, joias e cabelos.
- Opção de look surpresa e botão de finalizar look.
- Estética de closet fashion com inspiração em jogos de vestir e tendências de blogueiras.

## Observação
Esta é uma versão inicial de demonstração: a modelo é uma ilustração CSS estilizada, não uma personagem 3D realista. O botão de finalizar e a pontuação são demonstrações locais. Para publicar na App Store, será preciso preparar a versão iOS e cumprir as exigências atuais da Apple.
